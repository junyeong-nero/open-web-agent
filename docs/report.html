약점7

일시적 오류를 영구 차단으로 다룬다

  • Hugging Face 작업 3건이 HTTP 429를 받았다. 프롬프트는 401·402·403·429를 받으면 그 사이트를 다시 시도하지 말라고 한다. 그래서 wv-Huggingface--4는 6스텝 만에 포기했다. 이번을 포함한 다섯 번의 실행 중 429가 나온 것은 두 번뿐이었다. 429는 잠시 기다리면 풀리는 속도 제한이다.
  • wv-Google Flights--6 검색 직후 ‘No results returned’가 보이자 13스텝을 남긴 채 바로 답했다. 반대로 UPS는 모든 URL이 application/blank 다운로드로 돌아오는 확실한 차단이었다. 그런데도 6번이나 다시 시도했다(om2w-92160852a6bb).

차단 규칙이 HTTP 상태 코드에만 맞춰져 있다. 그래서 일시적인 429는 너무 일찍 포기하고, 상태 코드 없이 다운로드로 오는 차단은 계속 다시 시도한다.

이 밖에 사소한 문제: 한국어 Booking 페이지를 본 뒤 영어 작업에 한국어로 답했다(wv-Booking--43). 스텝 한도에서 낸 최선 답변에 outcome 줄이 빠진 경우가 1건 남았다(om2w-dd44c665cec1, #167 이후). 아멕스 비교 체크박스는 label이 클릭을 가로챘지만, 요소가 화면 밖에 있고 불안정해서 #152의 label 우회가 동작하지 않았다.

자가 평가는 믿을 만한가

에이전트는 답 끝에 succeeded·partial·blocked 중 하나로 스스로 평가한다. 행은 이 자가 평가이고, 열은 검증 결과다.

스텝과 토큰은 어디에 쓰이나

정답 실행은 대부분 짧다. 실패한 실행은 스텝 한도 근처까지 간다. 점 하나가 실행 하나이고, 세로 막대는 중앙값이다.

환경 요인

이번 실행은 한국 IP의 headless Chromium에서 돌았다. 결과의 상당 부분은 에이전트가 아니라 이 환경이 정했다.

  • Google 검색 차단. 21개 실행이 google.com/sorry를 만났다. 그중 4건은 Bing·위키백과나 다른 사이트로 넘어가 정답을 냈다. 시작 사이트가 막힌 뒤 다른 출처로 정답을 낸 실행은 모두 7건이다.
  • 지역 차이. 16개 실행에서 원화 가격(Amazon, Google Flights, Airbnb)이나 한국어 페이지(Booking index.ko.html, Google 지도, Bing)가 나왔고, Healthgrades와 Uniqlo는 지역을 이유로 막았다. Amazon에서는 한국으로 배송되지 않는 상품의 가격이 숨겨져 최저가 비교가 불가능했다(wv-Amazon--8). 벤치마크 arm에 --locale(#122)을 지정하지 않았다.
  • 속도 제한. Hugging Face 429는 3건, Brave 검색 429는 1건이다. 5개를 병렬로 같은 IP에서 돌리면 같은 사이트 작업이 동시에 몰린다. WebVoyager 작업이 사이트별로 4개씩 연달아 있기 때문이다.
  • 바뀐 웹. 정답 48건 중 11건은 2023년 데이터셋의 참고 답과 값이 다르다. 사이트 내용이 바뀌었기 때문이다(애니메이션 흥행 순위, HomePod 색상, 보상 판매가 등). 참고 답과 글자 그대로 비교하면 정답 수가 크게 줄어든다. Coursera의 ‘Credit Eligible’ 필터는 아예 사라졌다.

방법과 한계

  • 실행. .worktrees/bench-0878dbe에 main을 고정했다. 실행 전에 bun run typecheck와 bun run test(273/273, 220.6초)를 통과시켰다. bun run bench로 100개 작업을 한 번씩 돌렸다. 모델 ID는 OpenAI /v1/models에서 최신 Luna가 여전히 gpt-6-luna인지 확인했다.
  • 검증. 100개 trace를 하나씩 읽었다. 답이 작업 조건을 모두 만족하는지, 답의 숫자와 이름이 스냅샷·텍스트 관찰에 실제로 있는지 확인했다. golden 작업은 참고 답과 비교했다. 시간에 따라 바뀌는 사실은 2023년 참고 답이 아니라 실행 당시 사이트가 보여 준 값을 기준으로 삼았다. 2023 Steam Awards 수상작 하나만 웹 검색으로 따로 확인했다.
  • 너그러운 판정과 엄격한 판정. 시작 사이트가 막혀 다른 공식 출처로 맞힌 6건, 조건은 채웠지만 답이 최소한인 4건도 정답으로 셌다. 둘 다 빼는 엄격한 기준으로는 정답이 38건이다.
  • 정정(2026-10-10). 처음 보고서에서는 wv-ESPN--27을 정답(‘Golden’ 팀 5개)으로 셌다. 판정 모델 A/B를 돌리면서, ESPN 전체 팀 검색에는 25개 항목(14개 팀)이 있고 5개는 상위 결과만 본 숫자임을 확인했다. 그래서 오답으로 바로잡았다(정답 49→48, golden 14→13).
  • 원인 분류. 정답이 아닌 실행마다 가장 직접적인 원인 하나만 골랐다. 루프나 지역 차이처럼 여러 요인이 겹친 경우가 많아서, 원인별 건수는 대략적인 크기로 읽어야 한다.
